Content notice

About this content

Everything in the exjsx demo archive is fictional. None of these businesses exists.

If you have arrived here from one of the fifty demo sites — the menopause clinic, the valve works, the refugee charity, the CPAP machine, the children's dentist, any of them — that business is not real. It has no premises, no staff, no products, no customers and no accreditations. It was invented by AI software about a day before you saw it.

Why these pages exist

exjsx is an open-source toolchain that lets AI coding agents build native Elementor websites. To show what it can do, we asked AI agents to invent fifty businesses across fifty industries and build a complete landing page for each one, end to end, in a single working day. The point of the exercise was the design and build capability — can an agent produce a page that looks like a real designer made it? — not the businesses themselves, which are set dressing.

These are demonstration builds, not case studies. No client commissioned any of them. No one was paid for any of them. Nothing in them describes real work for a real customer.

The frozen copies served under /showcase/<name>/live/ carry this notice inside the page itself and are excluded from search indexing.

Read the full notice

The tool

Every layout here was written by an agent, in JSX.

exjsx compiles typed JSX components into native, editable Elementor V4 pages — no runtime, no lock-in. Open any of these in the normal Elementor editor and keep working. Free and MIT.
