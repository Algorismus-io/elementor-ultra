The pitch

COLDSTART is a two-day single-track conference about what actually runs in production, with no sponsor talks and every speaker required to show real incident data. The page is a typographic poster: dates, city, and the speaker list at enormous scale.

Sections it decided on

  1. Type wall: name, dates, city
  2. Single track, stated as a rule
  3. Speaker list at scale with talk titles
  4. The no-sponsor-talks policy
  5. Schedule as a plain two-column grid
  6. Hallway track, workshops and the incident clinic
  7. Tickets, and the pay-what-you-can allocation
  8. Code of conduct and how it is enforced
