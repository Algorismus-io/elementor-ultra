04 / REFUSALS

What we refuse to list, and why.

We do not list avoided emissions, cookstoves, forestry offsets, or anything where the counterfactual is an argument rather than a measurement.

The test is simple and we apply it the same way every time: if the tonne only exists because of a story about what would otherwise have happened, it is not a tonne we can hand you evidence for.

Avoided emissions

The counterfactual is unobservable. There is no sample to take.

Cookstoves

Usage estimates drift, and nothing in the field can be re-measured later.

Forestry offsets

Reversal risk is real and the buffer pool is an accounting device, not a measurement.

Forward credits

A promise is not a tonne. Sample first, issue after.

Unnamed labs

If we cannot name the instrument and the run, we cannot defend the number.
