How it works

Save a file. The site updates. The gates run.

01 · WRITE

JSX components

Pages are small typed components — pages/*.page.jsx, shared components/, tokens in theme.mjs. Tailwind-style tw="" shorthand, real units, useTheme(). Typed props fail at build time, not in front of a client.

02 · LOOP

exjsx dev --gates

Watch → millisecond rebuild → diff-driven deploy over REST → hot reload in the preview → verification gates re-check changed pages at 1200, 1920 and 390 px. A save lands on the live site in seconds.

03 · OWN

Native Elementor

The output is standard Elementor V4 atomic JSON via an authoritative server-side validator — backups and rollback included. Open the page in the editor, hand it to a client, walk away. No runtime, no lock-in.

The stack

Five pieces. Use all of them, or just one.

PiecePackageWhat it does
Compiler + CLI@algorismus/elementor-jsxJSX → native Elementor V4 JSON; build, deploy, lint, media, import, and the exjsx dev live loop.
MCP server@algorismus/elementor-ultra-mcp~90 tools for any MCP-capable agent: build, refactor, govern pages, design system, HTML→Elementor convert.
