The pitch

Boardsmith turns a script into consistent storyboard frames with the same characters, locations and lenses across every panel. The page is a split-screen scroller: script text on one side, the frame it generated on the other.

Sections it decided on

  1. Split hero: script line and the frame it produced
  2. Character lock: the same face across 60 panels
  3. Lens and framing controls that mean something
  4. Shot list export into the formats ADs actually use
  5. Six styles, from rough marker to full comp
  6. Rights, training data and what you own
  7. Pricing per project, not per image
  8. Board your next script
