The pitch

Avers Frame is a one-person architectural photography studio shooting completed buildings for practices and their award submissions. The page is a quiet index of projects, priced and dated, with the photographs doing all the persuading.

Sections it decided on

  1. Name, discipline, city, one sentence
  2. Numbered project index with year and practice
  3. Full-bleed plate one: interior
  4. Selected clients, set as a plain list
  5. Full-bleed plate two: exterior at dusk
  6. How a shoot runs: half day, full day, two day
  7. Licensing and usage terms in plain language
  8. Enquiry line and lead time
