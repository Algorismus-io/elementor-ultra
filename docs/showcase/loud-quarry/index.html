The pitch

Loud Quarry is a three-day festival held in a disused granite quarry with four stages and no VIP tier. The page is a screaming poster wall: lineup as the hero, tickets as the only action.

Sections it decided on

  1. Torn-poster hero with dates and quarry name
  2. Full lineup wall, day by day, headliners at scale
  3. Four stages described in one line each
  4. Ticket tiers as ripped stubs
  5. Getting there: coach, camp, quarry rules
  6. Last year in twelve photographs
  7. What is banned, plainly listed
  8. Ticket bar that sticks to the bottom
