Audience

Homeowners with solar panels considering a battery

The pitch

Housecell is a modular home battery you can start with one 5kWh unit and stack to four, with an app that shows the actual payback in pounds. The page is a bento grid where every tile is one number the buyer is trying to work out.

Sections it decided on

  1. Bento hero: payback tile, capacity tile, blackout tile
  2. Sizing: how many units your house actually needs
  3. Blackout behaviour and what stays on
  4. Tariff arbitrage: charging cheap, using expensive
  5. Installation: one day, MCS certified
  6. Warranty and the cycle guarantee
  7. Real numbers from four installed homes
  8. Book a survey
