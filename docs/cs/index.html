Padesát za den

Padesát vymyšlených značek. Padesát skutečných stránek v Elementoru.

Jeden běh, padesát zadání, zhruba jeden vývojářský den. Každé zadání pojmenovalo fiktivní firmu, publikum a vizuální archetyp — a odtud to převzal agent: art direction, paleta, typografie, texty, obrazový materiál a nativní build v Elementoru přes exjsx. Vlevo je skutečný uložený JSON hero sekce z filmu č. 2 — povrch, který agenti až doteď psali ručně. Vpravo typovaná komponenta, která ho generuje a kde chyby selžou při buildu, ne až na webu vašeho klienta.

Zálohy před každým zápisem. Serverový validátor odmítne vadné stránky ještě před uložením. Rollback, vždy. Halucinující agent vám web nerozbije.

GATES

1200 · 1920 · 390

ŽIVĚ — SMYČKA V BĚHU (SKUTEČNÉ ŘÁDKY LOGU Z HOUSEMAIT)

Ten řádek FAIL je celá pointa. Gates jsou automatické pass/fail kontroly na 1200, 1920 a 390 px — desktop, široký displej a mobil. Agent vidí verdikt při každém uložení a v tom dalším se opraví. Kontrola výsledku je zabudovaná přímo ve smyčce, není to skript, na který si máte vzpomenout na konci.

05

Stack

Pět dílů. Použijte všechny, nebo jen jeden.

01

KOMPILÁTOR + CLI

@algorismus/elementor-jsx

Typovaný JSX → nativní JSON Elementoru V4. Build, deploy, lint, média, import — a živá smyčka exjsx dev.

02

MCP SERVER

@algorismus/elementor-ultra-mcp

90+ nástrojů pro libovolného MCP agenta: stavba stránek, refaktoring, správa design systému, převod HTML do Elementoru.

03

DOPROVODNÝ PLUGIN

Plugin pro WordPress · GPL

Autoritativní REST cesta pro zápis na webu: serverová validace, zálohy, rollback, sondy oprávnění.

04

OVĚŘOVACÍ STUDIO

@algorismus/elementor-ultra-studio

Po každém deployi: pass/fail kontroly ve třech šířkách, kontrola zdraví webu a měření layoutu — automatizované přes Playwright.

05

LOKÁLNÍ WORDPRESS

@algorismus/elementor-ultra-playground

Skutečný WordPress + Elementor z předpřipraveného snapshotu, během vteřin. Čistý Node — bez Dockeru.

LOOP ........ npx exjsx dev <site-dir> --gates
              <site-dir> = project folder from setup (exjsx init)
              save -> ms rebuild -> diff deploy -> hot reload
              -> pass/fail verify at 1200 / 1920 / 390 px viewports

VERIFY ...... after setup: npx eu-studio check --pages /
              expect: pass:true, gates green at all three widths

ON FAILURE .. every write is backed up first; per-page rollback via

              elementor_page_list_backups). base_hash optimistic
              concurrency; op_id idempotency.
